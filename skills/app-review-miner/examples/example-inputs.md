# 예시 입력

## 예시 1. 앱 이름만 있는 경우

입력:

```text
픽크닉 구글플레이 리뷰 분석해서 사용자 불만, 기능 요청, 만들 만한 MVP 뽑아줘.
```

기대 동작:

- 링크를 바로 요구하지 않는다.
- 검색/추론을 먼저 시도한다.
- 공식 리뷰 확인 실패 시 표시한다.
- 데이터 부족을 분리하고도 리포트를 완성한다.

## 예시 2. 리뷰 텍스트 붙여넣기

입력:

```text
아래 리뷰 30개 분석해서 문제점과 백로그 뽑아줘.
```

기대 동작:

- 리뷰를 유형별로 분류한다.
- 반복 불만을 찾는다.
- 기능 요청을 분리한다.
- GitHub issue 스타일 백로그를 만든다.

## 예시 3. 경쟁 앱 3개 비교

입력:

```text
북마크 앱 A, B, C 리뷰를 비교해서 한국형 AI 링크 정리 앱 MVP 기회 찾아줘.
```

기대 동작:

- 각 앱을 따로 요약만 하지 않는다.
- 공통 불만을 추출한다.
- 경쟁사 약점을 비교한다.
- 하나의 MVP 콘셉트로 합성한다.

## 예시 4. 낮은 별점 리뷰 중심

입력:

```text
1~2점 리뷰 중심으로 이 앱이 왜 욕먹는지 분석하고 개선 우선순위 뽑아줘.
```

기대 동작:

- 치명 문제를 우선 파악한다.
- 감정 강도를 평가한다.
- 바로 고칠 것과 나중에 고칠 것을 분리한다.

## 예시 5. 사업 아이디어 도출

입력:

```text
명상 앱 리뷰를 분석해서 기존 앱들이 못 푸는 문제와 돈 될 만한 서비스 아이디어 찾아줘.
```

기대 동작:

- 사용자 불만을 시장 기회로 바꾼다.
- 유료화 가능성을 평가한다.
- MVP 후보를 점수화한다.
