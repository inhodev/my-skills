# 기회 점수화 기준

각 MVP 기회는 아래 7개 기준을 1~5점으로 평가한다. 리뷰 데이터가 부족하면 "가설 점수"라고 표시하고, 근거가 확인된 경우에만 강하게 주장한다.

## 평가 기준

1. 불만 빈도: 얼마나 반복적으로 등장하는가
2. 고통 강도: 사용자가 얼마나 강하게 불편을 표현하는가
3. 해결 난이도: 48시간 MVP에서 해결 가능한가
4. 결제 가능성: 사용자가 돈을 낼 만한 문제인가
5. 경쟁사 방어력: 기존 앱이 쉽게 따라 할 수 있는가
6. 차별화 가능성: 새로운 포지셔닝이 가능한가
7. 한국 시장 적합도: 한국 사용자, 대학생, 소상공인, 인디해커, SaaS 운영자에게 맞는가

## 점수 해석

- 25점 이상: 즉시 MVP 후보
- 19~24점: 실험 가치 있음
- 13~18점: 보조 기능 후보
- 12점 이하: 우선순위 낮음

## 작성 규칙

- 각 점수 옆에 근거 리뷰 요약이나 확인된 출처를 붙인다.
- 근거가 약하면 점수 앞에 "가설"을 붙인다.
- 해결 난이도는 점수가 높을수록 빠르게 검증하기 쉽다는 뜻으로 사용한다.
- 경쟁사 방어력은 점수가 높을수록 기존 앱이 따라 하기 어렵다는 뜻으로 사용한다.
- 총점만으로 결정하지 말고 불만 빈도, 고통 강도, 48시간 구현 가능성을 함께 본다.
