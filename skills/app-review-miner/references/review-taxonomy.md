# 리뷰 분류 체계

리뷰를 단순 감상으로 요약하지 말고 사용자 문제, 기능 요청, 감정 강도, 시장 기회로 분류한다.

- 온보딩 문제
- 로그인/인증 문제
- 속도/성능 문제
- 버그/크래시
- 결제/구독 문제
- 가격 불만
- UI 복잡도
- 검색/탐색 문제
- 알림 문제
- 동기화 문제
- 데이터 손실
- 고객지원 불만
- 광고 과다
- 기능 부족
- 기능 과잉
- 신뢰/보안 우려
- 개인정보 우려
- 업데이트 이후 악화
- 플랫폼 호환성 문제
- 한국어/현지화 문제

## 감정 강도 분류

1. 가벼운 불편: 쓰는 데 큰 문제는 없지만 거슬리는 불편
2. 반복 사용에 방해되는 불편: 계속 쓰면 피로가 쌓이는 문제
3. 이탈 가능성이 있는 불만: 대체 앱 탐색이나 사용 중단으로 이어질 수 있는 문제
4. 환불/삭제/별점 1점 수준의 강한 불만: 결제 취소, 삭제, 강한 비난으로 나타나는 문제
5. 신뢰 붕괴 또는 강한 분노: 개인정보, 데이터 손실, 사기 의심, 반복 장애처럼 서비스 신뢰를 무너뜨리는 문제
