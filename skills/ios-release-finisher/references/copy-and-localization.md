# 스토어 문구와 현지화 품질

## 사실 추출

문구를 쓰기 전에 다음을 실제 코드와 화면에서 찾는다.

- 핵심 사용자가 누구인지
- 첫 실행 후 사용자가 완료하는 핵심 작업
- 경쟁 앱과 구별되는 실제 기능
- 유료·무료 경계
- 계정·네트워크·기기 요구사항
- 데이터와 콘텐츠의 출처

확인되지 않은 기능과 수치는 쓰지 않는다.

## 한국어 초안 규칙

- 첫 문장은 앱이 해결하는 일을 말한다.
- 기능보다 사용 결과를 앞에 둔다.
- 한 문장에 핵심 하나만 쓴다.
- 문장을 쉼표로 이어 붙이지 않는다.
- 같은 조사와 어미를 연속으로 반복하지 않는다.
- 기능 목록은 목록으로 두고 억지 산문으로 만들지 않는다.
- `혁신적인`, `완벽한`, `강력한`, `손쉽게`, `새로운 경험`은 구체적 근거가 없으면 삭제한다.
- `최고`, `1위`, `유일`, `보장`은 검증 가능한 자료와 표시 권리가 없으면 금지한다.
- Apple 기능명과 상표는 공식 표기를 사용한다.

## AI 말투 검사

- 추상적인 도입부 삭제
- 같은 의미의 형용사 중복 삭제
- “통해”, “제공합니다”, “경험해 보세요” 반복 축소
- 세 문장 이상 비슷한 길이와 리듬이면 다시 편집
- 앱 이름을 불필요하게 반복하지 않음
- 모든 문장을 소리 내어 읽었을 때 실제 운영자가 쓴 문장처럼 자연스러운지 확인

## 필드 제한

- 이름 2~30자
- 부제목 30자 이하
- 프로모션 문구 170자 이하
- 설명 4,000자 이하, HTML 사용 금지
- 키워드 100바이트 이하
- 새로운 기능 4,000자 이하

최신 제한은 실행 시 Apple 공식 App Store Connect Help로 재확인한다.

## 키워드

- 앱 이름과 회사명을 반복하지 않는다.
- 경쟁사명과 오해를 유도하는 표현을 쓰지 않는다.
- 사용자 검색 의도와 실제 기능의 교집합만 남긴다.
- locale별로 별도 조사한다.
- 설명 본문에 키워드를 기계적으로 반복하지 않는다.

## 현지화

- 직역 대신 해당 언어권의 사용 장면과 표현을 기준으로 다시 쓴다.
- 앱 내부 지원 언어와 스토어 현지화를 혼동하지 않는다.
- 같은 locale이 App Info와 App Store Version 양쪽에 필요한지 확인한다.
- 스크린샷 fallback 때문에 다른 언어 이미지가 노출되는지 확인한다.
- 법률 문서는 언어별 관할과 실제 데이터 흐름을 보존한다.
