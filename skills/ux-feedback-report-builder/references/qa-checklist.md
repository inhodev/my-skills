# 납품 전 체크리스트

사용자에게 보고할 때 이 목록을 그대로 붙이고, 확인 못 한 항목은 "미확인"이라고 쓴다. 통과한 척하지 않는다.

## 구조
- [ ] 페이지 수가 약속한 분량(20 또는 30)과 정확히 일치
- [ ] 표지: 로고 + "사용자 피드백 보고서"만, 카드·소개 문구 없음
- [ ] 2p에 조사 목적/방법/개요/분석 방법/읽는 방법 + 메인 화면 캡처
- [ ] 3p 통계 행에 "N명 중 M명"만 (심각도·점수 없음)
- [ ] 참가자 페이지 = 참가자 수 (1인 1페이지)
- [ ] 마지막에서 두 번째 묶음에 "수정 완료를 확인하는 방법" 재검증 시나리오
- [ ] 마지막 페이지: 단기/중기/장기, 다음 테스트에서 확인할 것, 한계(긍정형), 긴 맺음 인용
- [ ] 페이지 번호 연속, 머리말/꼬리말 앱 이름 정확

## 글
- [ ] `lint_text.py` 통과 (대시 0건, 영문 라벨 0건, 타임스탬프 0건, 심각도/점수 0건, 녹화 시간 0건)
- [ ] 참가자 발언 원문 유지 (분석 md의 인용과 대조)
- [ ] 결론부에 비유 압축 없음, "먼저/다음으로/마지막으로" 직설
- [ ] 한계 박스가 다음 의뢰로 잇는 문장
- [ ] 조사 목적에 약점 기능 선언 없음, "녹화" 언급 없음
- [ ] 리스트가 명사형 종결이 아님
- [ ] 인원 표기가 표지·개요·본문에서 모순 없음
- [ ] 같은 인용이 주제 페이지에서 반복되지 않음
- [ ] 참가자 A~H 외 실명·연령·성별·기기 모델 0건

## 캡처
- [ ] 모든 이미지가 원본 해상도(절반 해상도 0건)
- [ ] 크롭 규칙: 상태바·주소창·브라우저 컨트롤 제거, 앱 탭바 유지, 데스크톱 브라우저 UI·작업표시줄 제거
- [ ] 개인정보 0건 (사진첩, 실명, 이메일, 계정, 북마크, 알림)
- [ ] 크기: 1장 62 / 2장 54 / 3장 46mm 이상
- [ ] 행마다 `--ih` 고정, 카드 상·하단 정렬
- [ ] 행 폭 합계 180mm 이하 (전 페이지 축소 증상 없음)
- [ ] 검정 띠 0건 (크롭 > 원본 증상)
- [ ] 이미지 가운데 홀로 띄운 페이지 없음, 오른쪽 플러시 없음
- [ ] 캡션 콜론 구분, 강조 1~2개, 2줄 이내

## 빨간 네모
- [ ] 화면 위 글자·라벨·화살표 0개
- [ ] 모든 마크가 `mark_review_sheet.py` 시트로 확인됨
- [ ] 색 있는 대상은 `find_color_band.py` 산출값 사용
- [ ] 크롭 경계에 잘린 대상 없음(있으면 크롭을 넓혔음)
- [ ] 마크가 대상 요소만 감쌈, 남발 없음

## 밀도
- [ ] `qa_pages.py`: 하단 여백 평균 29% 이하, 40% 초과 0페이지
- [ ] 넘쳐서 잘린 페이지 0개 (시트에서 하단 확인)
- [ ] 관찰 박스 아래 빈 공간 없음

- [ ] Chrome 임시 프로필 청소됨
- [ ] 프로젝트 표준 문서에 이번 새 규칙 반영됨
